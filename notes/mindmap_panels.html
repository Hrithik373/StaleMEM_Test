Can a cheap model reliably decide which memories are still true?

STALE / CUPMem reproduction

Reproduction + stress test · MLRC / TMLR · ACL/EMNLP workshops

Assistants keep long-term memories about their users. New information can make an old memory false without ever contradicting it, and the STALE benchmark shows most models miss this.

The paper's fix, CUPMem, decides what is still true at the moment memory is written. It scores 68.0%, the best on STALE. We check whether that result reproduces, and whether it still holds when the deciding model is small and cheap.
